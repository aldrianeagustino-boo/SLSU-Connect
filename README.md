# SLSU Connect — Realtime Student Portal Prototype

Isang lightweight, cloud-connected web application para sa SLSU students na nagtatampok ng:
- 📅 Class Schedule Manager
- ⏰ Deadline Tracker
- 🌐 Live Online Group Workspaces (Powered by Firebase Realtime Database)
- 📝 Reviewer Pad
